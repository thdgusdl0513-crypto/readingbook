
# 교무실 도우미

교사용 교무 업무 도우미 프로그램입니다. 입력한 자료는 사용하는 기기 안에만 저장되고, 이 폴더의 파일에는 학생 명단이나 학교 정보 같은 개인정보가 들어 있지 않습니다.

## 기능
- **홈**: 오늘까지 할 일, 학사일정 달력(학사일정·창체 일정·내 일정), 교사 시간표, 학급 시간표(엑셀 올리기, 내 시간표·우리 반 고정, 직접 수정), 이번 주 급식(나이스). 오늘까지 할 일을 뺀 카드는 제목을 눌러 접고 펼 수 있고 상태를 기억합니다.
- **성적관리**: 학기말 성적 종합일람표 엑셀로 학생별 신경 써야 할 과목, 성취도(A~E)와 석차등급(1~5) 분석
- **할 일**: 담임·수업·업무 분류와 마감일이 있는 스티커 메모와 완료 체크
- **학사일정**: 나이스 오픈API로 학교 학사일정 불러오기, 내 일정 추가
- **창체 일정**: 창의적체험활동 일정 엑셀(자율·자치, 동아리, 진로, 봉사)
- **예산**: 비목별 배정액·집행·집행률·잔액, 추경 변경 이력
- **기록 작성**: 행특, 교과세특, 자율·자치, 동아리 기록과 연말 전체 복사. 자율·자치는 창체 일정과 연결되고, 교과세특·동아리는 출석부·동아리 명단을 올려 학생을 고를 수 있습니다. ✨ AI 초안 쓰기(요청문 복사 또는 Gemini 연결)
- **상담 관리자**: 상담 타임라인, 학부모 문자 도우미(요청문을 복사해 AI 채팅창에 붙여넣는 방식), 상담 신청 받기(학생이 신청하고 선생님이 승인, 아래 설명 참고)
- **학생 기록 관리**, **조퇴증·외출증 발급**(블루투스 프린터 또는 일반 인쇄), **결석신고서**(우리 학교 양식 사진·PDF를 올려 그 위에 인쇄 가능)
- 설정: 프로그램 이름·학교 정보·D-day, 백업과 복원, 새 학년 초기화, 앱 잠금, PC·휴대폰 연동

## 처음 사용
1. 프로그램을 열면 초기 비밀번호 `0000`을 입력한 뒤 새 비밀번호를 정합니다. (8자 이상, 영문 대문자·소문자·특수문자 포함) 기기에 화면 잠금이 있으면 `비밀번호 없이 사용`을 골라도 됩니다.
2. 오른쪽 위 설정(톱니바퀴)에서 프로그램 이름, 학교 이름, 담임 학급을 입력하고 D-day를 추가합니다.
3. 학생 기록 관리 탭에서 엑셀/CSV로 학생 명단을 불러옵니다.
4. 학사일정 탭에서 나이스 오픈API 인증키(open.neis.go.kr에서 무료 발급)를 넣고 학교를 검색해 선택합니다.
5. 홈의 시간표 칸에서 교사별 시간표, 전체 학급 시간표 파일을 올리고 내 이름과 우리 반을 고정합니다.

비밀번호는 복구할 수 없습니다. 잊으면 잠금 화면의 `초기화`로 모든 자료를 지우고 처음부터 시작해야 합니다. 화면에 `버전 ...`이 적혀 있어 어떤 버전인지 확인할 수 있습니다.

## Windows 설치 파일 만들기
1. https://nodejs.org 에서 LTS 버전을 설치합니다.
2. 이 폴더(`index.html`, `main.js`, `preload.js`, `package.json`)에서 명령 프롬프트를 열고 한 줄씩 실행합니다.
```
npm install --save-dev electron electron-builder
npm run build
```
3. `dist` 폴더의 `GyomuHelper Setup 1.0.0.exe`를 설치합니다. 다른 컴퓨터에는 이 설치 파일만 옮기면 되고 Node.js는 필요 없습니다.
4. 폴더는 `C:\gyomu-helper`처럼 한글과 공백이 없고 OneDrive 밖인 곳에 두면 빌드 오류가 적습니다.

## 휴대폰·패드에서 사용하기
1. `index.html`을 GitHub Pages 같은 무료 정적 호스팅에 올려 https 주소를 만듭니다. (저장소는 Public, Settings → Pages에서 Branch `main`, `/ (root)`)
2. 패드·휴대폰 브라우저에서 그 주소를 열고 `홈 화면에 추가`를 누릅니다.
3. 파일 이름이 `index (1).html`처럼 바뀌지 않게 `index.html`로 올립니다. 새 버전은 같은 이름으로 덮어 올립니다.

## PC와 패드 연동 (구글 시트)
개인정보가 없는 자료(할 일·메모, 내 일정, D-day, 시간표, 창체 일정)만 본인 구글 시트로 주고받습니다. 학생 명단, 상담, 기록, 성적, 예산은 연동하지 않습니다.
1. 새 구글 시트를 만들고 `확장 프로그램` → `Apps Script`에 `gyomu-sync-sheet.gs` 내용을 붙여넣습니다.
2. 맨 위 `SYNC_TOKEN`을 나만 아는 연동 암호로 바꾸고 저장합니다.
3. `배포` → `새 배포` → 유형 `웹 앱`, 실행 계정 `나`, 액세스 `모든 사용자`로 배포하고 권한을 허용합니다.
4. 나온 웹 앱 주소(끝이 `/exec`)와 연동 암호를 PC와 패드 각각의 설정 → `PC·휴대폰 연동`에 넣고 `지금 동기화`를 누릅니다. 자료가 있는 기기에서 먼저 누르세요.
5. 이후에는 프로그램을 열 때 자동으로 맞추고, 상단 구름 버튼으로 바로 맞출 수 있습니다.

`gyomu-sync.gs`는 구글 드라이브에 파일로 저장하는 이전 방식이니 시트 방식(`gyomu-sync-sheet.gs`)을 쓰면 필요 없습니다.

## ✨ AI(Gemini) 연결
기록 작성 탭의 `Gemini 연결 설정`에서 설정합니다. 쓰지 않아도 되는 선택 기능입니다.
1. aistudio.google.com 에 구글 계정으로 로그인해 API 키를 만듭니다. (무료 사용량 있음)
2. 키를 붙여넣고 `연결 테스트`를 누릅니다. "연결됨"이 나오면 됩니다.
3. 모델 이름이 "없다"고 나오면 `모델 목록 불러오기`를 눌러 목록에서 고르거나, 모델 칸을 비우고 다시 테스트하면 자동으로 고릅니다. 직접 쓴 모델 이름은 자동으로 바꾸지 않습니다.
4. "high demand"는 구글 서버가 붐빈다는 뜻이며 잠시 뒤 다시 하면 됩니다. 앱이 자동으로 몇 번 다시 시도합니다.
- 키는 그 기기에만 저장되고 동기화·파일에 들어가지 않습니다. 다른 사람과 키를 공유하지 마세요.
- 학생 이름·학번은 기본으로 "학생"으로 바꿔 보내지만, 메모에 쓴 다른 개인정보는 그대로 구글로 갑니다. 학교 지침을 확인하세요.
- AI 글은 초안입니다. 반드시 읽고 고쳐서 쓰세요.

## 상담 신청 받기 (학생 신청 → 선생님 승인)
선생님마다 자기 구글 시트와 스크립트를 따로 만듭니다. 자세한 순서는 `reservation/README.md`를 보세요.
1. 새 구글 시트에 `gyomu-reserve.gs`를 붙여넣고 `ADMIN_TOKEN`을 바꾼 뒤 웹 앱으로 배포합니다.
2. 상담 관리자 탭 맨 위 `상담 신청 받기`에 웹 앱 주소, 관리 암호, 학생 페이지 주소를 넣습니다.
3. 상담 시간을 만들고, 나오는 `학생용 링크`를 학생에게 보냅니다.
4. 학생이 신청하면 같은 패널에서 승인·거절합니다.

## 다른 선생님과 나눠 쓸 때
- 이 폴더에는 개인정보가 없고, 저장 자료는 각자의 기기 안에만 있어서 서로 공유되지 않습니다. (공유용은 저장 이름이 따로 분리되어 있습니다.)
- 나이스 인증키, Gemini 키, 구글 스크립트 주소·암호는 각자 만들어 넣어야 합니다.
